Introduction

Vue d'ensemble
de la méthode

Une production vidéo publicitaire complète réalisée intégralement avec des outils IA, en 7 phases séquentielles. Chaque phase nourrit la suivante.

Principe fondamental : La précision du langage à chaque phase est ce qui transforme une idée en vidéo cohérente et professionnelle. Un prompt vague produit un résultat vague. Un prompt chirurgical produit un résultat maîtrisé.

01
Phase 01

Brief &
Analyse produit

Tout commence par une analyse précise du produit réel et la définition d'un cadre créatif clair avant d'écrire la moindre ligne de prompt.

1
Ce qu'on définit

Cadrer l'univers
avant tout

Avant d'écrire un seul prompt, trois paramètres doivent être verrouillés : le scénario narratif, l'identité visuelle du produit, et les choix créatifs de base.

1
Analyser le produit réel : photographier le vrai pot sous plusieurs angles. Mémoriser chaque détail du label — couleurs exactes, typographies, textes, hiérarchie des bandes.
2
Définir le scénario : liste des scènes dans l'ordre narratif. Chaque scène = une situation, une émotion, une action.
3
Cadrer les paramètres créatifs : genre, âge, contexte narratif, ambiance (chaleureuse, dynamique, lumineuse), style visuel (Wes Anderson ici), localisation.
Style Wes Anderson Antananarivo Palette pastels Symétrie

02
Phase 02

Création du
personnage

Le character sheet est la clé de voûte du projet. Sans personnage verrouillé dans les moindres détails, la cohérence entre scènes est impossible.

Character Sheet — Noro
NOM : Noro ÂGE : 22 ans ORIGINE : Malgache // Caractéristiques physiques TEINT : warm light brown skin, golden undertone VISAGE : soft round face, dark expressive almond eyes CHEVEUX : natural dark brown, high messy bun, loose strands framing face // Tenue signature HAUT : mustard yellow oversized distressed knit sweater, ripped elbow details BAS : rust-orange wide-leg trousers PIEDS : barefoot (intérieur) // Référence image FILE : perso.png ← uploader à chaque génération
2
Pourquoi c'est critique

Un personnage
verrouillé pixel par pixel

Seedance 5.0 n'a aucune mémoire entre les générations. Si les descriptions varient d'une scène à l'autre, le personnage change. La solution : un character sheet unique, figé, réutilisé verbatim.

✗
Descriptions vagues
"Une jeune femme malgache"
"Vêtements colorés"
"Cheveux attachés"
✓
Descriptions verrouillées
"warm light brown skin, golden undertone, soft round face"
"mustard yellow oversized distressed knit sweater with visible ripped elbow details"
"natural dark brown hair in a high messy bun with loose strands framing face"

Workflow : Générer le personnage seul d'abord (fond neutre, plein corps). Valider. Uploader perso.png comme character reference dans toutes les scènes suivantes.

03
Phase 03 — La plus importante

Structure des
prompts image

Chaque prompt image est construit en 8 blocs logiques. L'ordre et la précision de chaque bloc déterminent la qualité du résultat.

"Un bon prompt image est une mise en scène écrite — position du corps, orientation, décor, lumière, objectif, cadrage — tout ce qu'un directeur de photographie communiquerait à son équipe."
Anatomie d'un prompt — 8 blocs obligatoires
SETUP
Position exacte du personnage, orientation du corps par rapport à la caméra, état initial de l'action
CHARACTER
Rappel complet des détails physiques et vestimentaires — jamais abrégé
DECOR
Chaque élément du décor, ses couleurs exactes, sa position dans le cadre, son état
PRODUCT
Description exhaustive du label — toutes les bandes, couleurs, typographies, textes exacts
ACTION
Ce qui se passe — beat par beat si nécessaire — gestes précis, expressions
CAMERA
Objectif (mm), position exacte, hauteur, angle, axe, framing, mouvement (ou locked-off)
LIGHT
Sources, directions, températures, qualités — chaud/froid, dur/diffus, pratique/artificiel
COLOR GRADE
Palette globale, dominantes colorées, contrastes, mood — "photorealistic cinematic 9:16"
3
Règles d'or

Ce qui fait la
différence

Règle 1
Objectif précis en mm

50mm ≠ 85mm ≠ 100mm macro. Chaque focale change le rapport entre personnage et décor, la compression spatiale, la profondeur de champ.

Règle 2
Orientation du corps au degré près

"Facing the camera" / "strict 90-degree side profile" / "three-quarter left angle" — jamais "de face" ou "de côté".

Règle 3
Label produit verbatim

Répéter l'intégralité des textes du label à chaque prompt où le produit apparaît. Raccourcir = erreur.

Règle 4
Deux sources de lumière en tension

Chaud/froid, intérieur/extérieur — ex : lumière fluorescente jaune boutique + lumière grise froide de pluie fenêtre. Le contraste crée la profondeur.

Exemple complet
Prompt complet — Scène 3 / Achat à l'épicerie

05
Phase 05 — La plus technique

Structure des
prompts animation

Le prompt animation part de l'image réelle générée — pas du prompt théorique. On décrit ce qu'on voit, et comment ça bouge.

5
Structure obligatoire

Le principe
des beats

Chaque mouvement est un beat. Chaque beat a un déclencheur, une durée, une amplitude mesurée et une qualité — lent, brusque, involontaire, élastique. Rien n'est vague.

"Camera is completely locked off. No camera movement whatsoever throughout the entire clip."

Cette phrase s'écrit en premier dans chaque prompt animation, sans exception. Elle empêche Seedance de faire des zooms ou pans non voulus.

Structure type d'un prompt animation
1. DECLARATION CAMERA Camera completely locked-off. No movement. 2. ETAT INITIAL Description exacte du premier frame (= l'image) 3. BEATS D'ACTION Beat 1 → déclencheur + mouvement + durée + amplitude Beat 2 → déclencheur + mouvement + durée + amplitude Beat N → ... 4. MOUVEMENTS AMBIANTS Vapeur, lumière, rideaux, objets secondaires 5. DURÉE TOTALE "Total clip duration: X to Y seconds."
Exemple — Beats d'animation / Couloir (Scène 1E Anti Rhume)
Wave 1
1→3
Force modérée. Chaque éternuement pitche le haut du corps vers l'avant et le bas. Main gauche grip le mur. Rebond involontaire. Bun ballotte.
Wave 2
4→7
Escalade. Plus de redressement entre éternuements. Corps incliné 30° en permanence. Main droite sur le mur. Bun quasi-défait. Chaque éternuement avance d'un demi-pas vers la caméra.
Wave 3
8→10
Maximum. Événement corps entier. Genou fléchi sur impact. Sneeze 9 : main quitte le mur. Sneeze 10 : le plus violent. Rebond lent, épuisement total.
Ambiant
Ampoule Edison se balance à chaque éternuement. Arc de balancement augmente avec l'intensité. Continue à osciller après le dernier. Cadre des photos se décale légèrement.
Durée totale : 7 à 8 secondes
Règles d'animation
🔒
Camera locked-off = règle absolue

Aucun zoom, aucun pan, aucun dolly. Si la caméra bouge dans le résultat, réécrire le prompt en insistant encore plus sur l'immobilité totale de la caméra.

📐
Amplitudes en centimètres ou degrés

"Bouge légèrement" = résultat imprévisible. "Drops 5 millimeters" / "rotates 15 degrees" / "lifts 3 centimeters" = résultat contrôlé.

⏱
Durées explicites en secondes

Préciser la durée de chaque beat : "over two full seconds" / "half a second" / "held for one full second." La durée totale du clip : toujours en fourchette (ex: 6 à 7 secondes).

🌊
Mouvements ambiants continus

La vapeur qui monte, la lumière qui pulse, le rideau qui dérive — ces éléments secondaires donnent vie à la scène sans distraire. Toujours les décrire séparément, en continu.

💪
Qualifier le caractère du mouvement

"Involontaire" / "délibéré" / "élastique" / "épuisé" / "brusque" — ces qualificatifs changent radicalement le rendu. Un éternuement "involontaire" ≠ un geste "délibéré et lent."

👁
Partir de l'image réelle

Le prompt animation décrit ce qu'on voit dans l'image générée — pas ce qu'on avait prévu. Si l'image a divergé du prompt original, adapter le prompt animation à la réalité.

Phase 06

Génération des
vidéos

Seedance 5.0 en mode image-to-video. L'image générée devient le premier frame. Le prompt animation devient la chorégraphie.

6
Workflow image-to-video

Mode Image-to-Video

1
Ouvrir Seedance 5.0 en mode Image-to-Video
2
Uploader l'image validée de la scène (générée en Phase 4) comme first frame
3
Coller le prompt animation correspondant
4
Vérifier le résultat : mouvements corrects ? caméra immobile ? durée conforme ?
5
Si la caméra bouge ou si l'animation est incorrecte : régénérer avec le prompt renforcé
6
Exporter le clip validé — nommer par numéro de scène pour faciliter le montage

⚠️ Exception Scène 8 : Le visuel graphique final n'est pas animé depuis une image de personnage — utiliser un still graphique créé séparément (Canva, Illustrator) comme first frame.

Problèmes fréquents & solutions
PROBLÈME
La caméra zoome ou fait un pan non voulu
SOLUTION → Répéter "camera is completely locked-off" 2 fois dans le prompt. Ajouter "absolutely no zoom, no pan, no tilt, zero camera movement."
PROBLÈME
Le personnage change de visage mi-clip
SOLUTION → Régénérer l'image source avec un meilleur character reference weight. Re-générer le clip depuis la nouvelle image.
PROBLÈME
Le label du produit est déformé dans l'animation
SOLUTION → Réduire les mouvements autour du produit dans le prompt. "The jar remains completely still throughout" si nécessaire.
ASTUCE
Générer 2-3 variantes de chaque clip
Choisir la meilleure au montage. Les variantes sont souvent plus utilisables que le premier résultat.

7
Post-production
Étalonnage colorimétrique

Unifier la palette Wes Anderson sur l'ensemble des clips — chaque génération IA produit des variations légères qu'il faut corriger. Anti Rhume : dominante rose-poudré/teal. Energy Boost : progression froid→chaud sur l'arc narratif.

Transitions

Cuts secs pour les scènes d'éternuements (rythme punch). Cuts plus doux pour les scènes d'application (respiration, relief). Pas de transitions stylisées — la cohérence vient du mouvement et de la couleur, pas des effets.

Sound design

Musique de fond (orchestration légère, Wes Anderson-esque). Effets sonores synchronisés : éternuements, ampoule qui se balance, vapeur de bouilloire, pluie épicerie, feuilles jacaranda. Voix off optionnelle pour la scène finale.

Titres & textes

Nom du produit, slogan, éventuels sous-titres en accord avec la palette graphique. La typo des titres doit résonner avec l'esthétique Wes Anderson : serif élégant, espacement généreux.

★
Clé de voûte

Les 3 piliers de
la cohérence

La cohérence visuelle sur l'ensemble d'une production multi-scènes avec l'IA repose sur trois principes non-négociables.

1
Character Reference fixe

perso.png uploadé à chaque génération image. C'est l'ancre physique du personnage. Sans lui, Noro change de visage d'une scène à l'autre et la narration s'effondre.

2
Label produit verbatim

À chaque scène où le produit apparaît, son label est décrit dans son intégralité avec les mêmes mots exacts. L'IA ne mémorise pas. Raccourcir = déformer.

3
Décor verrouillé

Les mêmes éléments de décor décrits avec les mêmes couleurs et positions dans chaque scène du même lieu. Répétition crée la continuité. Variation crée la discontinuité.

"Chaque génération IA est amnésique. La cohérence ne vient pas de la machine — elle vient de la précision et de la discipline du rédacteur de prompts."
+
Pour aller plus loin

Adapter la méthode
à d'autres projets

Cette méthode est universelle. Elle s'applique à tout produit, tout personnage, tout style visuel. Voici comment l'adapter.

Ce qui change selon le projet
Style visuel : Wes Anderson → Cinéma vérité → Bollywood → Minimaliste scandinave
Personnage : Adapter le character sheet complet. Tout verrouiller avant la première génération.
Palette : Définir 3-4 couleurs dominantes et les répéter dans chaque prompt Color Grade
Localisation : Décrire la ville/quartier avec ses détails spécifiques — architecture, lumière naturelle, rue
Produit : Photographier le produit réel sous toutes les angles. Mémoriser chaque élément du packaging.
Ce qui ne change jamais
Structure en 8 blocs : Setup → Character → Decor → Product → Action → Camera → Light → Grade
Character reference : Toujours uploader une image de référence du personnage
Camera locked-off : Toujours écrire cette phrase en premier dans chaque prompt animation
Beats d'action : Toujours décomposer l'animation en beats numérotés avec durées
Répétition du label : Toujours décrire le produit en intégralité à chaque apparition
Applications possibles
🧴
Produits cosmétiques

Même méthode — insister sur les reflets, les textures, les effets sur la peau. La lumière est encore plus critique.

🍽
Restauration / Food

Adapter les scènes autour de la préparation, du service, de la dégustation. La vapeur et la texture sont les éléments clés.

👗
Mode & vêtements

Le décor prend moins d'importance — le personnage et le mouvement des vêtements deviennent le centre. Beats de marche, de pose, de tissu qui vole.

🏠
Immobilier

Focale grand-angle, décor ultra-détaillé, lumière naturelle dominante. Le personnage peut devenir secondaire au profit de l'espace.

📱
Tech & applications

Intégrer les écrans dans les scènes. Décrire les UI précisément. La main qui interagit avec le produit devient l'action centrale.

🎵
Événementiel / concerts

Les mouvements ambiants prennent le dessus : lumières, foule, fumée. Le personnage est dans le flux plutôt que l'agent principal.
